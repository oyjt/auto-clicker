# 自动点击器

<!-- impeccable:product-schema 1 -->

## Platform
macOS 原生桌面应用。

## Stack
实现假设：SwiftUI + AppKit + CoreGraphics，使用 Swift Package 构建，不依赖第三方库。用户要求 mac 原生交互。

## Users
需要在 Mac 上重复点击一个或多个固定位置的用户。

## Product Purpose
摆放有编号的点击靶点，编辑每点参数，通过悬浮操作栏开始、暂停、继续和停止按顺序循环点击。

## Capabilities and Constraints
- 启动/关闭悬浮控制、添加/删除靶点、拖动控制栏、隐藏靶点但保留执行。
- 操作栏默认顶部居中横向排列，记住最后位置；不可见位置回退到默认位置。
- 左侧六点抓手，悬停张手、拖动握手；拖动前暂停，不自动恢复。
- 操作栏主按钮开始/暂停/继续；停止并重置放在右键菜单、主窗口及菜单栏，Esc 保留。
- 长按靶点显示通用和高级设置；执行时操作栏和靶点使用微信绿。
- 点击周期、按住时长、循环次数、逐点重复、点击类型、随机位置和延迟。
- 使用 macOS 辅助功能权限发送鼠标事件；未授权时禁止执行。
- 支持多个显示器坐标、参数本地保存。
- 全局 Control + Option + Space 开始/暂停/继续；运行期间注册 Esc 停止，退出运行后释放。
- 暂停保留已完成进度，未完成的单次操作在继续时重试；位置或参数修改后从头开始。
- 用户明确选择保留现有多点入口，不折叠、不删除多位置功能。
- 操作栏图标采用无独立色块的样式；显隐图标表达下一步动作。
- 当前实现范围不包括手机上的滑动手势。

## Brand Commitments
支持日夜间切换，默认跟随系统；支持中文、英文，默认跟随系统。用户指定符合 macOS 设计规范，合适的 motion，微信绿（#07C160）主色和执行状态，自定义 Mac 风格应用图标，按用户参考图采用开放圆环与鼠标光标组合，默认浅灰白底板与清晰的深绿色图形，不保留狙击镜刻度。Carbon 图标为可选。

## Open Decisions
应用名已确认为“自动点击器”；English 为 Auto Clicker。
